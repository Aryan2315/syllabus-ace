# 📚 Syllabus Ace

Syllabus Ace is a modern web application that helps students organize, manage, and access their academic syllabus efficiently. It provides an easy-to-use interface for browsing subjects, tracking progress, and keeping syllabus information in one place.

---

## 🚀 Features

* 📖 View semester-wise syllabus
* 📂 Organized subject management
* 🔍 Quick and easy navigation
* 📱 Responsive design for desktop and mobile
* ⚡ Fast performance with Vite
* ☁️ Backend powered by Supabase

---

## 🛠️ Tech Stack

**Frontend**

* React
* TypeScript
* Vite
* Tailwind CSS

**Backend**

* Supabase

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Aryan2315/syllabus-ace.git
```

Navigate to the project

```bash
cd syllabus-ace
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

---

## 🔧 Environment Variables

Create a `.env` file in the project root and add your Supabase credentials.

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```
